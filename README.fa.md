# خودم‌ساز

خودم‌ساز بازار فارسی و راست‌به‌چپ محصولات دست‌ساز است. بازدیدکنندگان می‌توانند آگهی‌های تأییدشده را ببینند و مستقیماً با سازنده گفتگو کنند. ثبت خرید، اظهار کاربر درباره همان محصول است.

برای راه‌اندازی محیط توسعه، تنظیم PostgreSQL و Docker و اجرای آزمون‌ها، [راهنمای پروژه](README.md) را ببینید. تنظیمات محرمانه را در فایل محلی محیط نگه دارید.
